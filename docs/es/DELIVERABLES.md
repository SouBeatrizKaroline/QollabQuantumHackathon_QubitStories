# Entregables

Cuatro videos completos narrados (aproximadamente 9min30s cada uno), 64 capítulos independientes, guiones, subtítulos editables, laboratorio Qiskit con ocho experimentos y documentación en cuatro variantes lingüísticas. El ZIP de ejecución contiene software y documentación, sin los archivos MP4 grandes. Los videos están alojados en este repositorio.
