# Create New Project — cómo completar

**Project Title**

Qubit Stories — Laboratorio multilingüe de aprendizaje cuántico

**Project description (214/240)**

Cuatro videos ilustrados y 64 capítulos en inglés, español, portugués de Brasil y de Portugal, vinculados a ocho experimentos Qiskit. Mira, predice, ejecuta y explica superposición, interferencia y entrelazamiento.

**Select Template (Optional)**

Deja la plantilla opcional sin seleccionar.

**Project shape**

Elige **Upload your own files** y carga `qollab-runtime.zip`. Mantén los archivos en la raíz. Los videos permanecen en GitHub y se abren mediante enlaces del laboratorio.

[Descargar el paquete Qollab](../../qollab-runtime.zip)

Copia el Project Card de este idioma en la página del proyecto y añade la dirección del repositorio. Ejecuta con un simulador gratuito, verifica en IonQ, publica bajo MIT, graba una demostración pública de 2–3 minutos y envía mediante el flujo del hackathon. Primero completa la declaración de autoría de los originales.

Git repository: https://github.com/SouBeatrizKaroline/qubit-stories

[Project Card](../../docs/es/QOLLAB_PROJECT_CARD.md)

La publicación de los materiales educativos en GitHub está completada. Quedan pendientes la importación en Qollab, las pruebas en simuladores gratuitos e IonQ, la publicación bajo MIT y el envío al hackathon. Una demostración pública separada de 2–3 minutos debe mostrar el laboratorio ejecutable; los videos educativos largos no la sustituyen.
