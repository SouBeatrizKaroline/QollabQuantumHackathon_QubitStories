# Deliverables

Four complete narrated videos (approximately 9min30s each), 64 standalone chapters, scripts, editable captions, an eight-experiment Qiskit lab and documentation in four language variants. The runtime ZIP contains software and documentation, without the large MP4 files. The videos are hosted in this repository.
