# Como criar o projeto no Qollab

**Project Title**

Qubit Stories — Trilingual Quantum Learning Lab

**Project description — 225/240**

A trilingual quantum learning lab: three illustrated videos and 48 chapters in English, Portuguese and Spanish, linked to eight Qiskit experiments. Watch, predict, run and explain superposition, interference and entanglement.

**Select Template (Optional)**

Deixe sem selecionar.

**Project shape**

Escolha **Upload your own files** e envie `qollab-runtime.zip`. O arquivo contém o laboratório visual e a documentação. Os vídeos ficam hospedados no GitHub e são abertos pelos links do laboratório; não envie os MP4s para o ambiente de execução Qollab.

Na aba Project Card, copie o texto de `QOLLAB_PROJECT_CARD.md`. Coloque o endereço do repositório em Git repository: https://github.com/SouBeatrizKaroline/qubit-stories

Pressione Run e escolha um simulador gratuito. Verifique as experiências e os links de capítulos. Publique o projeto como executável sob licença MIT. Complete a declaração de autoria dos vídeos originais e prepare uma demonstração pública de 2 a 3 minutos mostrando o laboratório. Depois faça a submissão no fluxo do hackathon.

Os três vídeos longos e os 48 capítulos são materiais educativos. Ainda não foi realizada publicação nem submissão do projeto no Qollab.
